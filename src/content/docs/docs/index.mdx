## Où en est le self-host ?

Le serveur actuel se déploie sur **votre compte Cloudflare**, avec une base PostgreSQL que vous choisissez. L’agent Windows accepte l’adresse de cette instance.

L’installation complète sur un VPS ou un NAS, sans Cloudflare, **n’est pas encore fournie** : le runtime serveur et le remplacement du stockage KV restent à préparer. [Comparer les modes d’hébergement](/docs/hebergement/).
