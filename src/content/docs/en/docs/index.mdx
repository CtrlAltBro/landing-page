## What can you self-host today?

The current server deploys to **your Cloudflare account**, with a PostgreSQL database of your choice. The Windows agent accepts your instance’s address.

A complete VPS or NAS installation without Cloudflare **is not provided yet**. A server runtime and a replacement for KV storage still need to be prepared. [Compare hosting options](/en/docs/hebergement/).
